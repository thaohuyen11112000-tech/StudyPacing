# StudyPacing
StudyPacing là nền tảng hỗ trợ tự học thông minh, giúp người học xây dựng thói quen học tập hiệu quả thông qua lập kế hoạch, quản lý thời gian và theo dõi tiến độ. Hệ thống kết hợp quản lý nhiệm vụ, Pomodoro và Time Blocking nhằm giảm trì hoãn, tăng khả năng tập trung và nâng cao năng lực tự học.
